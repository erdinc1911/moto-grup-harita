# Moto Grup – Çevrimdışı Türkiye haritası

Bu depo yalnızca Moto Grup uygulamasının indirdiği çevrimdışı harita dosyasını barındırır.
Uygulamanın kodu burada değildir.

- Dosya: `turkiye.pmtiles` (vektör harita, PMTiles biçimi)
- Her ayın 1'inde otomatik güncellenir.
- İndirme adresi: https://github.com/erdinc1911/moto-grup-harita/releases/latest/download/turkiye.pmtiles

Harita verisi © [OpenStreetMap](https://www.openstreetmap.org/copyright) katkıcıları,
[ODbL](https://opendatacommons.org/licenses/odbl/) lisansı ile. Harita derlemesi
[Protomaps](https://protomaps.com).
